# 3D Models Module

Convert 3D models between formats and extract textures, animations, or materials.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/3d/convert` | Convert 3D model format |
| POST | `/api/3d/extract` | Extract data from 3D model |

## POST `/api/3d/convert`

**Content-Type**: `multipart/form-data`

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `file` | File | Yes | 3D model file (max 200MB) |
| `format` | string | Yes | Target: `glb`, `gltf`, `obj`, `usdz`, `fbx`, `stl`, `ply` |
| `optimize` | boolean | No | Apply mesh optimization |
| `compress` | boolean | No | Apply Draco compression (GLB only) |

```bash
curl -X POST http://localhost:4001/api/3d/convert \
  -F "file=@model.gltf" \
  -F "format=glb" \
  -F "optimize=true" \
  -F "compress=true" \
  --output model.glb
```

## POST `/api/3d/extract`

**Content-Type**: `multipart/form-data`

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `file` | File | Yes | GLB/GLTF model file |
| `extractType` | string | Yes | `textures`, `animations`, or `materials` |

**Response**: JSON file with extracted metadata.

```bash
curl -X POST http://localhost:4001/api/3d/extract \
  -F "file=@model.glb" \
  -F "extractType=textures" \
  --output textures.json
```

### Notes

- Input must be GLB or GLTF for extraction
- Uses @gltf-transform for processing and draco3dgltf for compression
- OBJ, STL, PLY, FBX conversions go through an intermediate GLTF step
